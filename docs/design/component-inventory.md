# جرد المكونات الأولي (Component Inventory) — منصة توا

> يبني على `design-system-foundations.md`. توثيق فقط — لا كود.
> **النطاق:** 🌐 مشترك · 🛍 ستورفرونت · 🏪 لوحة التاجر · 🛡 لوحة المدير.

### اصطلاحات تسري على كل المكونات التفاعلية (لا تُكرر أدناه)

- **الحالات القياسية:** افتراضي، Hover، Pressed، Focus (بـ `focus.ring`)، Disabled، وLoading حيث يوجد فعل غير فوري. تُذكر أدناه الحالات **الإضافية** فقط.
- **الإتاحة القياسية:** تباين §7، تشغيل كامل بلوحة المفاتيح، نص بديل للأيقونات الوظيفية، أهداف لمس ≥44 (ستورفرونت) / ≥40 (لوحات). يُذكر أدناه ما يزيد عليها فقط.
- **RTL القياسي:** المحاذاة تبدأ من اليمين، الأيقونات الاتجاهية تنعكس، الأكواد/الهواتف/البريد LTR معزولة اتجاهياً (§8). يُذكر أدناه الخاص فقط.

## 1. الأزرار

| المكون | النطاق | التفاصيل |
|---|---|---|
| **زر** | 🌐 | **الغرض:** تنفيذ فعل. **الأشكال:** أساسي (ممتلئ بـ `accent.current` — واحد لكل شاشة)، شبح (حد رفيع)، نصي، خطر (للأفعال المدمرة)، وحجمان (افتراضي/صغير للجداول). **حالات إضافية:** Loading بـ Spinner داخلي مع تجميد العرض (لا يقفز التخطيط). **RTL:** الأيقونة قبل النص من اليمين. **استجابة:** يتمدد لعرض كامل في نماذج الهاتف. |
| **زر أيقوني** | 🌐 | **الغرض:** أفعال متكررة ضيقة المساحة (⋮ إجراءات الصف، ✕ إغلاق، نسخ). **الأشكال:** شبح/صامت. **إتاحة إضافية:** تسمية نصية آلية (aria) إلزامية + Tooltip عند الإشارة. **استجابة:** الحد الأدنى للهدف اللمسي يتجاوز حجم الأيقونة المرئي. |

## 2. حقول النماذج

| المكون | النطاق | التفاصيل |
|---|---|---|
| **غلاف الحقل** (Field wrapper) | 🌐 | **الغرض:** البنية الموحدة لكل حقل: تسمية علوية دائمة + الحقل + نص مساعد أو رسالة خطأ (يتبادلان نفس السطر). **حالات:** عادي، خطأ (حد `status.critical` + رسالة)، معطّل، للقراءة فقط. **إتاحة:** ربط برمجي للتسمية والخطأ بالحقل؛ علامة «اختياري» نصية (الافتراض: كل الحقول مطلوبة). |
| **إدخال نصي** | 🌐 | أشكاله: عادي، مع أيقونة، مع بادئة/لاحقة ثابتة (مثل `.tawa.ly` للنطاق — اللاحقة LTR معزولة). التحقق الفوري عند مغادرة الحقل (نمط المتطلبات: «الرقم مستخدم مسبقاً»). |
| **منطقة نص** | 🌐 | للأوصاف والأسباب الإلزامية (رفض م.1.3.3، حظر م.1.3.9). تكبير رأسي فقط؛ عدّاد أحرف عند وجود حد. |
| **قائمة اختيار** (Select) | 🌐 | فئة المنتج، فلاتر الحالة. القائمة المنسدلة على `surface.raised`؛ تصبح Bottom sheet في هاتف الستورفرونت. |
| **Combobox (بحث ضمن قائمة)** | 🌐 | للقوائم الطويلة (اختيار تاجر عند المدير، مدينة الشحن). **إتاحة إضافية:** إدارة تركيز معلنة للقارئات، وإبراز نص التطابق. |
| **إدخال تاريخ** | 🏪🛡 | فترات الخصم (1.5.1) وفلاتر السجل. منتقٍ بتقويم عربي RTL، أرقام غربية، واختيار مدى (من/إلى). **[افتراض تصميمي]** التقويم ميلادي. |
| **إدخال رقمي** | 🌐 | الأسعار والكميات والمخزون. أرقام غربية، محاذاة موحدة، أزرار ± في محدد الكمية (🛍) بأهداف ≥44، ويرفض غير الأرقام بلطف (لا مسح صامت). |
| **هاتف** | 🌐 | مفتاح دولة ثابت `+218` **[افتراض]** + الرقم LTR داخلياً. حجر أساس التتبع دون حساب (2.2.8). |
| **كلمة مرور** | 🏪 | إظهار/إخفاء + مؤشر قوة **[توصية من وثيقة التحليل]**. |
| **إدخال OTP** | 🏪 | 6 خانات تتنقل آلياً، لصق الرمز دفعة واحدة، وعدّاد إعادة الإرسال (60 ث **[افتراض]**). **إتاحة:** يقبل الإدخال كحقل واحد للقارئات. |

## 5. الملاحة

| المكون | النطاق | التفاصيل |
|---|---|---|
| **قائمة جانبية** | 🏪🛡 | 248 مرجعياً، يمين الشاشة. البند النشط بخلفية `accent.current` الفاتحة ونص داكنه؛ شارات عدّ (طلبات، مخزون، طوابير المدير)؛ للموظف تُخفى البنود غير المصرّح بها (لا تُعطَّل). أسفلها بطاقة المتجر/المدير. **استجابة:** Drawer تحت `bp.desktop`. **إتاحة:** رابط «تخطَّ إلى المحتوى». |
| **شريط علوي** | 🌐 | لوحات: عنوان سياقي + بحث شامل + جرس (**Pending product decision — D7**) + قائمة المستخدم. ستورفرونت: شعار التاجر + بحث + سلة بعدّاد + «تتبع طلبي». يلتصق أعلى الشاشة. |
| **تبويبات** | 🌐 | تقسيم شاشة واحدة (حالات الطلبات بعدّادات، أقسام الإعدادات، تبويبات المظهر). التبويب النشط بمؤشر سفلي بـ `accent.current`. تنزلق أفقياً في الهاتف مع تدرج حافة. **إتاحة:** أسهم لوحة المفاتيح بين التبويبات. |
| **مسار تنقل** (Breadcrumb) | 🛍🛡 | الرئيسية / التصنيف / المنتج (2.1.5) ومسارات المراجعة الإدارية. الفاصل ينعكس في RTL. يُختصر في الهاتف إلى «‹ رجوع للتصنيف». |
| **ترقيم صفحات** | 🌐 | أسفل الجداول والشبكات؛ أرقام غربية، أسهم منعكسة RTL، وعرض «1–20 من 128». في هاتف الستورفرونت: «عرض المزيد» بدل الترقيم. **[توصية]** |
| **Stepper (مؤشر خطوات)** | 🌐 | معالج الإعداد (1.2.1)، خطوات الـ Checkout، ومسار حالة الطلب (1.5.4) بشكله الأفقي المعروض لا التفاعلي. المكتمل ✓، الحالي بارز بنقطة نابضة حيث يليق، القادم خامل. |

## 6. البطاقات

| المكون | النطاق | التفاصيل |
|---|---|---|
| **بطاقة عامة** | 🌐 | وحدة معنى واحدة: `surface.card` + `radius.card` + حد hairline، رأس اختياري (عنوان + إجراء). لا تداخل بطاقات عميقاً. |
| **بطاقة منتج** | 🛍 | صورة بنسبة موحدة (مربعة **[توصية]**) + اسم بسطرين حداً + سعر (+ مشطوب عند الخصم) + شارة نفاد/خصم + «أضف للسلة» (ظاهر دائماً في اللمس، عند الإشارة في المكتبي). **إتاحة:** البطاقة كلها رابط واحد والزر فعل منفصل. |
| **بطاقة ملخص/مؤشر** (Stat) | 🏪🛡 | رقم `type.numeric` كبير + تسمية + دلالة اتجاه اختيارية. قابلة للنقر نحو شاشة التفصيل. أربع بطاقات كحد أقصى في الصف. |
| **بطاقة قالب** | 🏪 | ✅ مبنية: معاينة مصغرة + اسم + وسوم (RTL ✓، متجاوب ✓) + شارة دورة الحياة من الباكند: «منشور — قالب المتجر» / «مسودة مثبتة» / «غير مثبت»، وإجراءات «تثبيت كمسودة» · «تخصيص ومعاينة» · «نشر» · «حذف المسودة» (المنشور لا يُحذف). |

## 7. الجداول وبدائلها

| المكون | النطاق | التفاصيل |
|---|---|---|
| **جدول بيانات** | 🏪🛡 | رؤوس `type.caption` خافتة، صفوف بحد `border.subtle`، Hover خفيف، أرقام Tabular بمحاذاة موحدة، الحالة شارةً، إجراءات الصف في قائمة ⋮، تحديد جماعي بشريط إجراءات يظهر عند التحديد. **حالات:** فارغ (نمط الحالة الفارغة داخل الجدول)، تحميل (صفوف Skeleton)، خطأ (رسالة + إعادة محاولة). فرز بالأعمدة **[توصية]**. |
| **قائمة أقسام قابلة لإعادة الترتيب** | 🏪 | ✅ مبنية (1.3.4): كل صف = رقم الموضع + عنوان قابل للتحرير + نوع القسم + مفتاح إظهار/إخفاء + زرَّي ↑/↓. الترتيب بالأزرار لا بالسحب فقط ⇒ يعمل بلوحة المفاتيح، وكل نقلة تُعلن في `aria-live` («نُقل «…» إلى الموضع 2 من 3»). إعدادات القسم الخاصة بالقالب تُعرض للقراءة فقط. |
| **تحرير موضعي** (Inline edit) | 🏪 | للتعديل السريع للمخزون (1.4.10): النقر يحول الخلية حقلاً رقمياً بزري ✓/✕، وصف واحد في وضع التحرير. **إتاحة:** إعلان الدخول والخروج من وضع التحرير. |
| **بطاقة صف (بديل الهاتف)** | 🏪🛡 | تحويل الصف: السطر الأول هوية (اسم/رقم طلب) + شارة الحالة؛ الثاني الرقم الحرج (مبلغ/متاح)؛ إجراء أساسي واحد ظاهر والبقية في ⋮. |

## 11. مكونات الحالات الست

| المكون | النطاق | التفاصيل |
|---|---|---|
| **حالة فارغة** | 🌐 | رسم بسيط + جملة + زر الإجراء الأول. شكلان: فارغة-حقيقية («ابدأ بإضافة أول منتج») وفارغة-بفلتر («لا نتائج — امسح الفلاتر»). |
| **Skeleton تحميل** | 🌐 | يطابق تخطيط المحتوى القادم (صفوف جدول، شبكة بطاقات، صفحة منتج)؛ بلا نبض عند `prefers-reduced-motion`. |
| **حالة خطأ** | 🌐 | ما حدث + ما العمل + «إعادة المحاولة»؛ داخل حدود المنطقة الفاشلة لا الشاشة كلها إن أمكن. |
| **حالة غير مصرّح** | 🏪🛡 | «ليست لديك صلاحية الوصول — تواصل مع مالك المتجر» + مخرج آمن؛ نبرة محايدة (1.5.8). |
| **صفحة صيانة المتجر** | 🛍 | حالة إلغاء النشر (1.2.5): شعار التاجر + رسالة مؤقتة أنيقة. ثابتة النمط لا تتبع تخصيص التاجر كاملاً (§4 توجيه بصري). |

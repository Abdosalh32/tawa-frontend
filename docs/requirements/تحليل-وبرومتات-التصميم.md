# الجزء الثاني: السيناريوهات (User Scenarios)

## سيناريوهات التاجر

### س1 — رحلة الانضمام الكاملة (Onboarding)
1. يفتح التاجر صفحة التسجيل ويدخل: الاسم، البريد، الهاتف، كلمة المرور (1.1.1)
2. يصله رمز OTP نصي → يدخله → يتفعّل الحساب (1.1.2)
3. معالج إعداد المتجر: اسم المتجر → اللغة → حجز النطاق الفرعي `mystore.tawa.ly` (1.2.1)
4. يصل للوحة التحكم بحالة "متجر غير منشور — بانتظار اعتماد الإدارة"
5. **حالة بديلة:** الرقم مستخدم مسبقاً → رسالة خطأ واضحة | لم يصل الرمز → إعادة إرسال بعد 60 ثانية

### س2 — تجهيز المتجر للنشر
1. يختار قالباً من المكتبة ويثبته (1.3.1، 1.3.2)
2. يضبط الألوان والشعار حسب هويته (1.3.3)
3. يرتب أقسام الصفحة الرئيسية بالسحب والإفلات (1.3.4)
4. يعاين النتيجة في بيئة معزولة (1.3.5)
5. يضيف منتجاته ثم يضغط "نشر المتجر" → **Checklist**: منتج واحد على الأقل ✓ سياسات إلزامية ✓ (1.2.4)
6. **حالة بديلة:** متطلب ناقص → زر النشر معطل مع توضيح الناقص

### س3 — إضافة منتج بمتغيرات
1. "منتج جديد" → الاسم، الوصف، الفئة، الصور، السعر الأساسي (1.4.3)
2. يفعّل "متغيرات" → يعرّف محورين: المقاس (S/M) واللون (أحمر/أزرق) → يتولد جدول 4 تركيبات (1.4.6)
3. لكل تركيبة: سعر ومخزون وصورة مستقلة (1.4.7)
4. يحذف تركيبة غير متاحة (أزرق/S) (1.4.8)
5. يحفظ → المنتج يظهر في القائمة

### س4 — دورة حياة الطلب
1. إشعار: طلب جديد #2481 (مدفوع ببطاقة / كاش عند الاستلام)
2. يفتح التفاصيل: العناصر، العنوان، رسوم الشحن (1.5.3)
3. ينقل الحالة: مؤكد → قيد التجهيز → جاهز للتسليم → مُسلَّم (1.5.4)
4. **حالة بديلة:** إلغاء الطلب → الكميات ترجع للمخزون تلقائياً (1.5.5)

### س5 — إدارة المخزون والتنبيهات
1. زبون يبدأ شراء → الكمية "محجوزة" 15 دقيقة (1.4.11) → تظهر في اللوحة: متاح / محجوز
2. المخزون ينخفض تحت الحد → تنبيه فوري للتاجر (1.4.12)
3. التاجر يعدل الكمية يدوياً بعد جرد (1.4.10)

### س6 — فريق العمل
1. التاجر يدعو موظفاً بالبريد (1.5.7)
2. الموظف يقبل الدعوة وينشئ كلمة مروره
3. التاجر يحدد صلاحياته: الطلبات فقط، بدون إعدادات (1.5.8)
4. **لاحقاً:** تعطيل الحساب وسحب الصلاحيات فوراً (1.5.9)

### س7 — إيقاف مؤقت
1. التاجر مسافر → "إيقاف استقبال الطلبات" (1.2.5)
2. زوار المتجر يرون صفحة صيانة أنيقة
3. الطلبات السابقة تبقى قابلة للإدارة من اللوحة

## سيناريوهات الزبون

### س8 — التصفح والشراء (المسار السعيد)
1. يفتح متجر `alafya.tawa.ly` → يتصفح المنتجات (2.1.1)
2. يبحث "شامبو" أو يفلتر: فئة + سعر 20–50 + لون (2.1.2–2.1.4)
3. صفحة المنتج: صور، وصف، اختيار متغير (2.1.5)
4. يضيف للسلة → يعدل الكمية والنظام يتحقق فورياً من المخزون (2.2.1، 2.2.2)
5. الدفع: عنوان + هاتف + مكان الاستلام (2.2.5) → كاش أو بطاقة (2.2.7)
6. تأكيد → رقم تتبع فريد + شاشة نجاح (2.2.6)
7. **حالة بديلة:** الكمية نفدت أثناء التصفح → "غير متوفر" وتعطيل زر الإضافة

### س9 — تتبع طلب بدون حساب
1. "تتبع طلبك" → رقم الطلب + رقم الهاتف (2.2.8)
2. تظهر حالة الشحنة كخط زمني: مؤكد → قيد التجهيز → جاهز → مُسلَّم

## سيناريوهات مدير المنصة

### س10 — اعتماد تاجر جديد
1. قائمة الانتظار: 5 طلبات (1.3.1)
2. يفتح طلب "فاطمة إدريس": البيانات + الوثائق المرفوعة
3. **قرار أ:** اعتماد → تفعيل رسمي + إمكانية النشر (1.3.2)
4. **قرار ب:** رفض بسبب مكتوب → يظهر للتاجر ليصحح ويعيد التقديم (1.3.3)

### س11 — ضبط مخالفة
1. أثناء فحص المنتجات (1.3.8) يجد منتجاً محظوراً
2. يحظره ويزيله فوراً + إشعار للتاجر مع الدليل (1.3.9)
3. تكرار المخالفة → تعليق المتجر بالكامل (1.3.4)
4. التاجر يعالج → فك الحظر (1.3.5)
5. كل العمليات تسجل في سجل التدقيق (1.3.13)

### س12 — إدارة الباقات
1. إنشاء باقة "احترافية": 500 منتج، نطاق مخصص، 3 موظفين، 50 د.ل/شهر (1.3.10)
2. تعديل الحدود لاحقاً (1.3.11)
3. أرشفة باقة قديمة — المشتركون الحاليون يستمرون (1.3.11ب)
4. تاجر دفع نقداً → تجديد يدوي مباشر (1.3.12)

## القسم أ: لوحة تحكم التاجر

### البرومت 1 — شاشات المصادقة (تسجيل، دخول، OTP، استعادة)

```
صمّم مجموعة شاشات المصادقة للتاجر في منصة «توا» للمتاجر الإلكترونية (4 شاشات في صفحة واحدة
مع تنقل بينها):

1) شاشة إنشاء حساب تاجر جديد:
   - حقول: الاسم الكامل، البريد الإلكتروني، رقم الهاتف (مع مفتاح ليبيا +218)، كلمة المرور
     مع مؤشر قوة، موافقة على الشروط
   - زر «إنشاء الحساب» + رابط «لديك حساب؟ سجّل دخولك»
   - تحقق فوري تحت كل حقل (مثال خطأ: «رقم الهاتف مستخدم مسبقاً»)

  - مسار التنقل (Breadcrumb): الرئيسية / العناية بالشعر / شامبو أرغان
  - اسم المنتج + رمز SKU صغير
  - السعر: 45 د.ل (وسعر مشطوب 60 د.ل + شارة «وفّر 15 د.ل»)
  - اختيار المتغيرات:
    - الحجم: أزرار (400مل / 750مل) — المختار بإطار أزرق
    - النوع: (عادي / مضاد للقشرة) — خيار غير متوفر يظهر مشطوباً ومعطلاً
  - مؤشر التوفر: «متوفر — تبقى 5 قطع فقط» (برتقالي إذا قليل)
  - محدد كمية (− 1 +) بجانب زر «أضف إلى السلة» كبير أساسي
  - أقسام قابلة للطي (Accordion): الوصف الكامل، سياسة الاسترجاع، معلومات الشحن

قسم سفلي: «منتجات مشابهة» — 4 بطاقات

صمّم أيضاً حالة toast تظهر بعد الإضافة: «تمت الإضافة إلى السلة ✓» مع زر «إتمام الشراء»
```

### البرومت 14 — السلة وإتمام الشراء (Checkout)

```
صمّم مسار الشراء الكامل للزبون (3 شاشات متتابعة في صفحة واحدة):

شاشة 1 — السلة:
- جدول العناصر: صورة + اسم + المتغير (أحمر/M) | سعر الوحدة | محدد كمية (− +) مع تحقق
  فوري: عند تجاوز المتاح تظهر رسالة «الكمية المتاحة: 3 فقط» | الإجمالي | زر حذف (×)
  بنقرة واحدة
- ملخص يسار: مجموع المنتجات، الشحن (يُحدد لاحقاً)، الخصم، الإجمالي — زر «إتمام الشراء»

شاشة 2 — بيانات الشحن والدفع:
- Stepper علوي: السلة ← الشحن والدفع ← التأكيد
- نموذج: الاسم، رقم الهاتف، المدينة (منسدلة بمدن ليبية)، العنوان التفصيلي، مكان
  الاستلام (المنزل/مكتب الشحن)، ملاحظات اختيارية
- اختيار طريقة الدفع — بطاقتان كبيرتان:
  أ) كاش عند الاستلام (أيقونة نقود)
  ب) بطاقة مصرفية (أيقونة بطاقة) — عند اختيارها تظهر حقول شاشة المعاملات: رقم البطاقة،
     الانتهاء، CVV
- ملخص الطلب الثابت يساراً مع رسوم الشحن محسوبة الآن

شاشة 3 — تأكيد النجاح:
- رسم نجاح ✓ كبير + «تم استلام طلبك!»
- رقم التتبع الفريد بارز جداً بخط كبير: «TW-2481-9X» مع زر نسخ
- ملاحظة: «احتفظ بالرقم — يمكنك تتبع طلبك به مع رقم هاتفك دون حساب»
- زرا «تتبع الطلب» و«مواصلة التسوق»
```

### البرومت 15 — تتبع الطلب (بدون حساب)

```

الحالة الأولى — نموذج الاستعلام:
- بطاقة مركزية أنيقة: حقل «رقم الطلب» (مثال: TW-2481-9X) + حقل «رقم الهاتف المستخدم
  في الطلب» + زر «تتبع»
- نص مساعد: «تجد رقم الطلب في رسالة التأكيد»
- حالة خطأ ظاهرة: «لا يوجد طلب مطابق — تأكد من الرقمين»

الحالة الثانية — نتيجة التتبع (صمّمها تحت النموذج):
- رأس: رقم الطلب + اسم المتجر + تاريخ الطلب
- خط زمني عمودي (Timeline) بحالات الشحنة:
  ✓ مؤكد (اليوم 10:30) ← ✓ قيد التجهيز (11:15) ← ● جاهز للتسليم (نشط الآن، نقطة نابضة)
  ← ○ مُسلَّم (رمادي بانتظار)
- بطاقة ملخص مصغرة: عدد العناصر، الإجمالي، طريقة الدفع، مكان الاستلام
- تصميم متوافق تماماً مع الهاتف (هذه الصفحة تُفتح غالباً من الجوال)
```

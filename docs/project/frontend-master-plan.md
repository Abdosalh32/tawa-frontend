## 2. المعمار المعتمد (لا يُغيَّر دون سبب)

Vite · React 19 · TypeScript · **CSS خام بـ Tokens دلالية** · بلا مكتبة UI · بلا Router بعد · بلا استمرارية (لا Storage ولا Cookies) · بيانات تجريبية محلية مكتوبة الأنواع · حالة معاينة مشتركة بـ `useSyncExternalStore` (ثيم الستورفرونت + السلة).

**أساسات لا تُكرَّر:** أنماط RTL العامة · الـ Tokens · بدائيات الواجهة · `AppShell`/`Sidebar`/`Topbar`/`Tabs`/`Table`/`DataTable`/`Pagination`/`Stepper`/`Drawer` · ملاحة التاجر المشتركة · ملاحة المدير المشتركة · قشرة الستورفرونت · قواميس الحالات في `src/types/status.ts` · أساسيات الثيم في `src/types/store-theme.ts`.

**التشغيل:** `npm run dev` → `http://localhost:5173/`

### ما نُفّذ في المرحلة 5 (Routing) — 17 أغسطس 2026
- **التبعية:** `react-router` 8.3.0 (وافق المالك على الخيار بعد عرض المقارنة؛ التبعية الثالثة الوحيدة بعد react/react-dom).
- **خريطة العناوين:** `/auth` · `/setup` · `/merchant/:storeId/{overview,products,products/new,products/:id/edit,categories,inventory,orders,orders/:orderId,discounts,appearance,team,settings}` · `/shop` + `/shop/products/:productId` + `/shop/{cart,checkout,tracking}` · `/admin/{...}` · `/design-system` · `*` صفحة 404.
- **العنوان مصدر الحقيقة لسياق المتجر (D5):** `MerchantStoreLayout` يزامن `:storeId` مع المخزن، والمعرف المجهول يعيد التوجيه؛ مبدّل المتاجر يبدّل المعرف ويحافظ على الشاشة.
- **تحميل كسول لكل شاشة:** الحزمة الرئيسة 266KB (كانت 509 — زال تحذير الحجم)، وكل شاشة chunk مستقل.
- **صدق المعرفات:** طلب/منتج مجهول في العنوان يعرض «غير موجود» الفعلية لا بيانات مفبركة.
- **كما خُطط:** حُرّاس المسارات مؤجلة حتى عقود مصادقة فعلية · البيانات التجريبية باقية · شريط المعاينة التطويري باقٍ لكنه صار روابط URL (NavLink).
- **المتبقي من الربط الداخلي:** بعض الأزرار العابرة الثانوية وفتات الخبز لم توصل بعد — تُستكمل تباعاً.

## 5. قواعد العمل لكل شاشة جديدة

1. اقرأ المتطلبات ووثائق UX/التصميم ذات الصلة، واستخرج الحقول والأفعال **الموثقة حصراً**.
2. افحص حالة Git — **وتوقّف إن وُجدت تغييرات غير مكوّمتة لا تتعلق بمهمتك**.
3. أنشئ فرعاً مركّزاً من الفرع الصحيح (عادةً `main`).
4. نفّذ ببيانات تجريبية محلية مكتوبة الأنواع.
5. أعد استخدام المكونات والـ Tokens — **لا تكرّر** ثيماً أو ملاحة أو سلة أو قاموس حالات.
6. تحقّق: لينت · بناء إنتاجي · خادم تطوير · كونسول نظيف · مكتبي · **هاتف 390px حقيقي** · RTL والمحتوى مختلط الاتجاه · لوحة المفاتيح.
7. أبلِغ: الملفات، السلوك، الافتراضات، المؤجلات، نتائج التحقق، حالة Git.
8. **لا staging ولا commit ولا push ولا PR إلا بطلب صريح.**

### أعراف الالتزام المتبعة (وأثبتت نفسها)
- كل شاشة فيها **أداة معاينة تطويرية موسومة** (fieldset بحد متقطع) لحالات: عادية/تحميل/فارغ/خطأ.
- كل فعل محلي موسوم صراحةً «معاينة محلية — لا حفظ فعلياً».
- الأفعال المدمرة بحوار يشرح الأثر + سبب إلزامي حيث تنص المتطلبات.
- ألوان الحالات محجوزة للدلالة، ولا أزرار «خضراء» زخرفية.
- لا بيانات تاجر داخلية في واجهة الزبون (لا SKU ولا مخزون ولا محجوز).
- التحقق البصري والوظيفي بقيادة المتصفح فعلياً (CDP) لا بالتخمين.
